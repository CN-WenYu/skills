# Two-Layer Explanation

First establish the learning goal, the audience's background, and the practical question to answer. Do not substitute analogy for definition or use terminology to simulate precision.

## Explain

The first layer is for a newcomer: use plain language and one concrete example close to the problem. Explain what it solves and what happens from input to outcome.

The second layer is for technical understanding: provide precise terms, the core mechanism, relevant data or control flow, applicability boundaries, and common exceptions. Mark parts that are uncertain or version-dependent when necessary.

## Output

Then provide:

1. A mapping between the intuitive explanation and technical terms.
2. The most likely misconception and its correction.
3. Three questions that test genuine understanding.
4. A small exercise, validation, or code-reading starting point.
